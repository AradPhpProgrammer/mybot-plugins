# دليل إضافات مجتمع MyBot

مرحبًا بك في الكتالوج الرسمي للإضافات مفتوحة المصدر لمحرك **MyBot Studio** — محرك البناء البصري (بدون كود) لروبوتات تيليجرام ذات الاستضافة الذاتية.

هذا المستودع هو فهرس مركزي ينشر فيه المبدعون والمطوّرون والمجتمع إضافات قابلة للتطوير لـ MyBot ويكتشفونها ويصونونها.

> 🌐 **اللغات:** [English](README.en.md) · [فارسی](README.fa.md) · [Русский](README.ru.md) · [العربية](README.ar.md)

## 🧩 كيف يعمل

توسّع الإضافات لوحة الاستوديو البصري لـ MyBot بعُقد مخصصة ولوحات إدارة وبوابات دفع وأدوات تحليلات وموصّلات API خارجية.

كل إضافة مجلد مستقل يحتوي:
1. `plugin.json` — البيانات الوصفية (الاسم، الإصدار، المؤلف، الوصف، الفئة، المدخلات/المخرجات، خطافات الواجهة).
2. معالجات الخلفية (موجّه FastAPI / منطق تنفيذ عقدة DAG).
3. مكونات الواجهة (عقدة React أو امتداد لوحة التحكم).

```
plugins/
├── my-awesome-plugin/
│   ├── plugin.json
│   ├── __init__.py
│   ├── node.py
│   └── README.md
```

### مثال التوصيف (`plugin.json`)

```json
{
  "id": "my_weather_node",
  "name": "Live Weather Provider",
  "version": "1.0.0",
  "author": "YourName",
  "category": "services",
  "description": "Fetches real-time weather forecasts based on user location.",
  "type": "canvas_node",
  "entrypoint": "node.py",
  "license": "AGPL-3.0"
}
```

## 📁 بنية المجلدات

تُنظَّم الإضافات حسب الفئة (راجع `categories.json` كمصدر واحد للحقيقة):

| المجلد | الفئة | أمثلة |
|---|---|---|
| `plugins/payments/` | بوابات الدفع والعملات الرقمية | ZarinPal, TRON, محافظ |
| `plugins/analytics/` | التحليلات واللوحات | عدّادات المستخدمين، سجلات الأحداث |
| `plugins/services/` | الخدمات وواجهات API الخارجية | الذكاء الاصطناعي، الطقس، الخطافات |
| `plugins/admin/` | الإدارة ومكافحة البريد المزعج | الحظر، الاشتراكات الإجبارية، التنبيهات |
| `plugins/messengers/` | المراسلون والتذاكر | الدعم المباشر، الجسور |
| `plugins/community/` | الألعاب والأدوات | الحاسبات، عُقد الترفيه |

## 🤝 قواعد المساهمة

1. **طلب Pull Request**: أنشئ مجلدًا `plugins/<plugin-id>/` مع توثيق واضح ومخطط إعداد صالح واختبارات.

2. **مفتوح المصدر وغير تجاري**: جميع الإضافات هنا **مجانية ومفتوحة** تحت **GNU AGPL-3.0** (أو رخصة OSI متوافقة). **لا تُقبل** الإضافات **التجارية أو المدفوعة أو الاحتكارية** في هذا الفهرس العام. على المؤلفين الراغبين في التربح تشغيل خدماتهم أو منصاتهم أو مواقعهم الخاصة.

3. **الصيانة المجتمعية**: إرسال إضافة يسمح للمجتمع بإصلاحها وصيانتها وتحديثها مع إصدارات المحرك الجديدة إذا أصبح المؤلف الأصلي غير نشط. لا يتحمل فريق MyBot المركزي المسؤولية القانونية عن الخدمات أو الإعلانات أو واجهات API أو محتوى إضافات الأطراف الثالثة.

4. **الأمان والجودة**: بدون كود مشفّر أو مبهم أو نَفّاذ من بُعد، بدون تتبع أو سرقة رموز أو أبواب خلفية. كل PR يخضع لتحليل أمني آلي ومراجعة كود.

## 📦 تثبيت إضافة في MyBot Studio

من لوحة التحكم: **Plugins** → بحث أو لصق رابط المستودع → **Install / Activate**. تظهر العُقدة فورًا على اللوحة.
